## 🚀 Featured Project

### [Batch Tracking Events Library](https://github.com/wellbarea/batch-tracking-library)

A lightweight event-tracking library designed to improve the reliability of analytics delivery in web applications.

- 💾 Local persistence for pending events
- 📦 Configurable event batching
- 🔁 Automatic retries with exponential backoff
- ⏱️ Configurable timeout for incomplete batches
- 🔌 Designed for integration with modern frontend frameworks

**Tech focus:** TypeScript, event queues, persistence, reliability, and reusable library architecture.

[View on GitHub](https://github.com/wellbarea/batch-tracking-library) · [View on npm](https://www.npmjs.com/package/batch-tracking-events-library)
